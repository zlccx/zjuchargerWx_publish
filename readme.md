# ZJU Charger

> 当前版本：v2.0.0

ZJU Charger 是一个面向浙江大学师生的充电桩查询微信小程序，用于快速查询附近充电桩的实时状态，并提供排序、筛选、收藏与导航等功能。

## 功能特性

- **实时定位**：基于微信定位能力获取用户当前位置
- **多维度排序**：支持智能排序、按距离排序、按空位排序
- **地图展示**：在地图上标记充电桩位置
- **筛选与搜索**：按校区、运营商筛选，按名称搜索；搜索与筛选条件互不冲突
- **下拉刷新**：首页与收藏页支持下拉刷新，随时获取最新状态
- **收藏管理**：按唯一键收藏充电桩，列表状态随最新数据同步，站点下线时显示收藏快照
- **一键导航**：从当前位置导航至目标充电桩
- **版本公告**：点击个人中心的版本号查看更新内容

## 核心实现

### 坐标转换

后端返回百度坐标（BD09），而小程序地图使用国测局坐标（GCJ02），`utils/geo.js` 中的 `bd09ToGcj02` 负责两者之间的转换。

### 距离计算

使用 Haversine 公式计算用户与充电桩之间的球面距离，结果以米为单位。

### 智能排序

以 500 米为区间对充电桩分组，组内按空闲数量降序排列，无空闲的充电桩统一排在最后。

### 状态管理

`store/index.js` 集中管理用户位置、充电桩列表、筛选条件与收藏列表，并通过 `update` 机制将状态变更同步至已注册的页面。对外不暴露内部状态对象，筛选（`applyFilter`）、排序（`applySort`）、收藏读写（`getFavorites` / `getFavoriteStations`）等均通过方法进行，避免外部直接修改 state。

### 收藏

收藏只记录站点的 `hash_id`，展示时与最新充电桩数据关联，因此状态随刷新保持最新；站点从数据源消失时回退到收藏时的快照并标记「已下线」。收藏数据通过微信本地缓存持久化，小程序启动时自动从缓存恢复。

### 版本公告

个人中心展示当前版本号，点击后弹出版本公告，说明本版本的新增与修复内容。

## 运行

1. 安装微信开发者工具
2. 克隆仓库：

   ```bash
   git clone https://github.com/zlccx/zjuchargerWx_publish.git
   ```

3. 复制 `.env.example` 为 `.env`，填入自己的小程序 AppID，然后生成项目配置：

   ```bash
   node scripts/gen-project-config.js
   ```

   （生成的 `project.config.json` 已被 `.gitignore` 忽略，不会提交）

4. 在微信开发者工具中选择「导入项目」，填写项目目录即可
5. 点击「编译」即可预览
